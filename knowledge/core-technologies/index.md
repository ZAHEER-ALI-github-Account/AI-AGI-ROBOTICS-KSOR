# Core technologies

* [Machine learning](machine-learning.md) - How computers learn patterns from data instead of following hand-written rules — supervised, unsupervised and reinforcement learning.
* [Deep learning](deep-learning.md) - Many-layered neural networks that learn their own representations from raw data — the technology behind modern vision, speech and language AI.
* [Reinforcement learning](reinforcement-learning.md) - Learning by trial and error from rewards — how AI mastered games and how robots learn to walk and manipulate.
* [Computer vision](computer-vision.md) - How machines learn to recognise, locate and segment objects in images and video — the eyes of most robots.
* [Natural language processing and large language models](natural-language-processing.md) - How computers learned to work with human language — from word vectors to Transformers, GPT-style models and instruction tuning.
* [SLAM — simultaneous localization and mapping](slam.md) - How a robot builds a map of an unknown place while working out where it is inside that map.
* [ROS — the Robot Operating System](ros.md) - The open-source software framework that most robotics research and many commercial robots are built on.
* [Large language models in robots](llms-in-robots.md) - How language and vision-language models became robot "brains" — from SayCan and PaLM-E to vision-language-action models like RT-2, π0, Gemini Robotics and GR00T.
* [Simulation and digital twins](simulation-and-digital-twins.md) - Why robots learn in virtual worlds first, how simulation-trained skills transfer to reality, and what a digital twin is.
